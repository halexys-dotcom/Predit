Política de Privacidade

Como o Predit trata — e, sobretudo, como não trata — a informação do utilizador.

Última atualização: 29 de setembro de 2026

100% Offline Sem recolha de dados Sem contas

1. Quem somos

O Predit é uma aplicação Android desenvolvida por Hugo Alexandre Henriques Correia (doravante "desenvolvedor", "nós"). Contacto: haconnect@outlook.pt.

Esta política descreve como o Predit trata a informação do utilizador.

2. Que dados recolhemos

Nenhum.

O Predit não recolhe, não transmite, não armazena em servidores externos e não partilha com terceiros qualquer dado pessoal do utilizador.

  • ✓100% OfflineNenhuma funcionalidade depende de Internet.
  • ✓Sem recolha de dadosNada sai do seu telemóvel.
  • ✓Sem contasNão existe registo nem login.
  • ✓Sem publicidadeNem rastreadores de terceiros.

Todas as informações que o utilizador introduz na app — tipos de turno, datas, horas, configurações de contrato — ficam armazenadas exclusivamente no próprio dispositivo do utilizador, numa base de dados local.

3. Ligações de rede

O Predit funciona integralmente offline. Nenhuma funcionalidade depende de ligação à Internet.

Versão distribuída pela Play Store: a app não pede permissão de rede e não efetua qualquer pedido HTTP.

Versão distribuída pelo GitHub Releases (canal alternativo, não disponível na Play Store): essa versão inclui um mecanismo de verificação e instalação de atualizações, que consulta um ficheiro público de metadados alojado no GitHub. Essa consulta não transmite qualquer dado pessoal — apenas um pedido HTTP anónimo ao ficheiro público.

4. Permissões

A versão distribuída pela Play Store não solicita qualquer permissão sensível. A app não acede à Internet, não acede à câmara, não acede aos contactos, não acede à localização e não recolhe identificadores do dispositivo.

A versão distribuída pelo GitHub Releases solicita duas permissões adicionais, exclusivamente para o mecanismo de atualização:

  • Internet — para consultar o ficheiro público de metadados de versão no GitHub.
  • Instalar pacotes — para instalar, por ação explícita do utilizador, o APK da versão mais recente.

Estas duas permissões não existem na versão publicada na Play Store.

5. Backups

O Predit permite ao utilizador exportar e importar backups da sua base de dados. Esses ficheiros são criados no armazenamento local do dispositivo, sob controlo exclusivo do utilizador. Não são enviados para nenhum servidor.

6. Crianças

O Predit é uma aplicação profissional destinada a maiores de 18 anos. Não recolhe intencionalmente dados de menores.

7. Direitos do utilizador (RGPD)

Como o Predit não recolhe nem processa dados pessoais em servidores próprios, não existe tratamento de dados sujeito ao RGPD por parte do desenvolvedor. Toda a informação está sob controlo exclusivo do utilizador no seu dispositivo.

O utilizador pode, em qualquer momento:

  • Apagar todos os dados desinstalando a app;
  • Fazer backup dos seus dados para um ficheiro local;
  • Restaurar um backup anterior.

8. Alterações a esta política

Esta política pode ser atualizada em caso de alteração de funcionalidades. A data no topo indica a versão em vigor.

9. Contacto

Para questões relacionadas com privacidade, contactar: haconnect@outlook.pt.
